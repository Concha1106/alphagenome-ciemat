# Objetivo

Replicar el experimento descrito en el paper de AlphaGenome para la variante chr3:197081044 TACTC>T en DLG1, asociada a un evento de exon skipping en tejido Artery_Tibial (GTEx), y evaluar si las predicciones obtenidas reproducen el
comportamiento descrito en la Figura 3b del artículo.

El trabajo se divide en dos fases principales:

1. Análisis inicial mediante score_variant(), orientado a detectar señales globales de alteración del splicing.

2. Comparación directa REF vs ALT mediante predict_variant(), orientada a validar estructuralmente el evento y preparar una futura visualización tipo Figura 3b.

## 1.2  VALIDACIÓN ESTRUCTURAL PRELIMINAR MEDIANTE GTF 

Objetivo:
Contrastar la junction candidata detectada tras el análisis con score_variant() con la anotación exónica de DLG1 en Ensembl GRCh38 release 115.

Esta validación se realizó como análisis preliminar después de observar un combined_score elevado y una junction larga candidata compatible con exon skipping.

## Entrada:
 - raw-data/2026-04-10-exp02-exon-skipping/Homo_sapiens.GRCh38.115.gtf (Ensembl)
Se generó el archivo intermedio interm-data/2026-04-10-exp02-exon-skipping/dlg1_exons.gtf a partir del GTF completo de Ensembl, filtrando únicamente los exones anotados para DLG1.

Junction evaluada: 197076685 - 197085579
Adaptación del gene_id: en AlphaGenome el identificador de DLG1 aparecía con versión: ENSG00000075711.21

En el GTF de Ensembl el gene_id aparece separado en dos campos:
- gene_id "ENSG00000075711"
- gene_version "22"

Por este motivo, para filtrar el GTF se utilizó el identificador sin versión:ENSG00000075711

## Comandos:
 - Filtrado de exones DLG1:
grep 'ENSG00000075711 'raw-data/2026-04-10-exp02-exon-skipping/Homo_sapiens.GRCh38.115.gtf | grep $'\texon\t' > interm-data/2026-04-10-exp02-exon-skipping/dlg1_exons.gtf

 - Identificación de exones en límites de la junction candidata:
awk '$3=="exon" && $5==197076685 {print $4, $5}' interm-data/2026-04-10-exp02-exon-skipping/dlg1_exons.gtf | sort -u
awk '$3=="exon" && $4==197085580 {print $4, $5}' interm-data/2026-04-10-exp02-exon-skipping/dlg1_exons.gtf | sort -u

 - Identificación de exones intermedios:
awk '$3=="exon" && $4>197076685 && $5<197085579 {print $4, $5}' interm-data/2026-04-10-exp02-exon-skipping/dlg1_exons.gtf | sort -u

La junction termina en 197085579, por lo que se consulta 197085580 para capturar el inicio del exón siguiente.

## Validación estructural refinada para la interpretación REF vs ALT:

Durante el desarrollo e interpretación del script predict_variant(), se refinó la validación estructural usando el transcrito de referencia de DLG1 marcado como MANE_Select.

### Objetivo:
Evitar la ambigüedad generada por las múltiples isoformas de DLG1 y disponer de un marco estructural concreto para interpretar las junctions REF vs ALT.

### Comando para identificar el transcrito MANE_Select:
```
grep 'gene_name "DLG1"' raw-data/2026-04-10-exp02-exon-skipping/Homo_sapiens.GRCh38.115.gtf | \
grep $'\ttranscript\t' | \
grep 'MANE_Select'
```
### Resultado:
- transcript_id: ENST00000667157
- transcript_name: DLG1-261
- strand: -
- tags: MANE_Select, Ensembl_canonical

### Extracción de exones del transcrito MANE_Select:
```
echo -e "chr\tstart\tend\tstrand\texon_number" > interm-data/2026-04-10-exp02-exon-skipping/dlg1_mane_select_exons.tsv

grep 'transcript_id "ENST00000667157"' raw-data/2026-04-10-exp02-exon-skipping/Homo_sapiens.GRCh38.115.gtf | \
grep $'\texon\t' | \
awk '{
    for(i=1; i<=NF; i++) {
        if($i == "exon_number") {
            exon = $(i+1)
            gsub(/"/, "", exon)
        }
    }
    print $1 "\t" $4 "\t" $5 "\t" $7 "\t" exon
}' >> interm-data/2026-04-10-exp02-exon-skipping/dlg1_mane_select_exons.tsv
```

Exones relevantes alrededor de la variante:
- exon 16: 197085580 - 197085756

Relación con las junctions REF vs ALT:
- REF: 197076685 - 197081050
- REF: 197081117 - 197085579
- ALT: 197076685 - 197085579

Interpretación:
Las junctions REF conectan los exones flanqueantes con el exon 17, mientras que la junction ALT conecta directamente el exon 18 con el exon 16, omitiendo el exon 17.

Esta comparación estructural apoya la interpretación de que la variante induce un patrón compatible con exon skipping del exon 17.
